# GeniusPilot C3 主线发布 — 2026-09-14

## 安装与更新入口

- 主线仓库：`JiangNanGenius/CarrotPilot-C3-ESCC`
- 主线分支：`genius/c3`
- C3 首次安装：`https://jiangnangenius.github.io/CarrotPilot-C3-ESCC/i`
- SSH 安装或切换主线：`curl -fsSL https://jiangnangenius.github.io/CarrotPilot-C3-ESCC/s | sh`

安装器始终拉取 `origin/genius/c3` 的最新提交。设备内更新器也只接受本仓库和该分支；SunnyPilot 远端保持只读。

## 本次主线功能

- 修复 C3 Panda 初始化、消息读取耗尽、内部组件通信有效性和 S 挡激活链路。
- 纵向控制以车辆仪表速度为基准，不使用 GPS 速度作为控制目标。
- 将驾驶员最高定速作为上限，道路限速作为正常规划目标；油门松开可建立临时目标，新道路限速、刹车、停车或退出控制会清除。
- 新增三段式限速偏移：默认 60 km/h 及以下 `+0`、70–80 km/h `+1`、90 km/h 及以上 `+2`，三档均可独立设置。
- 自动提高最高定速只使用原始道路限速，不把限速偏移重复放大。
- SCC-V 与 SCC-M 增加独立减速强度，并在 Onroad HUD 显示实际生效状态。
- 红灯停车任务在短暂识别丢失时继续按行驶距离推进；提供停止线提前量和信号识别/起步提示音。
- 修正 Cruise 菜单持久化、中文常见字符、限速分段控件可见性及 HUD 巡航来源显示。

## 安全边界

限速偏移不是执法容差。弯道、前车、红灯和其他安全约束仍可把目标压到更低。已有测试证明及时识别时停车目标明显改善，但非常晚才识别到的红灯仍可能没有足够制动距离；不得依赖自动红灯停车替代驾驶员制动。
