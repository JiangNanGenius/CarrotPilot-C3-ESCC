# GeniusPilot C3 主线发布 — 2026-09-18

## 安装与更新入口

- 主线仓库：`JiangNanGenius/CarrotPilot-C3-ESCC`
- 主线分支：`genius/c3`
- C3 首次安装：`https://jiangnangenius.github.io/CarrotPilot-C3-ESCC/i`
- SSH 安装或切换主线：`curl -fsSL https://jiangnangenius.github.io/CarrotPilot-C3-ESCC/s | sh`

安装入口继续拉取 `origin/genius/c3`，因此本次发布不更换用户已有的短链接。设备参数目录不会被更新覆盖。

## 本次修复

- 油门松开低于有效道路限速时，规划恢复到道路限速；高于道路限速时仍可保留驾驶员的临时目标，但不超过最高定速。
- 临时油门目标只绕过 SCC-V/SCC-M 弯道减速，不绕过前车、红灯、测速摄像头和安全减速；新限速、刹车、停车、退出控制或测速摄像头会清除临时目标。
- Hyundai 原厂导航测速摄像头严格使用 `Navi_HU.SpeedLim_Nav_Cam`，生效时使用同一 `Navi_HU` 报文的原始限速且偏移为零。原始位和规划生效状态均进入日志，HUD 显示“测速限速”。
- 增加静止前车低速保持：在低速接近已停止前车时建立停车任务，雷达短暂丢失一秒内不会立即向前蠕动；前车稳定移动或驾驶员踩油门后才释放。
- 红灯停车任务在模型短帧、短暂识别丢失和短暂纵向退出时继续保存；制动距离不足时 HUD 显示“停车点过近 请接管”。
- 静止跟车目标设置调整为 2.5–6.0 米、0.5 米步进，新安装默认 3.5 米。升级保留设备现有值，不主动重置。
- 启动阶段仅对笼统的内部通信告警增加八秒宽限；进程、摄像头、CAN、Panda 和雷达的具体故障仍立即报告。
- Onroad 左上角定速依据字号增至 40/44，并增加测速限速来源。
- Hyundai/Kia 转向辅助力度增加 100%–110% 设置，此车默认 105%；只把正常转向请求略微放大，车辆与 Panda 的 384 扭矩上限保持不变。
- Steering 菜单增加 EPS 大角度故障保护开关和 0.9–2.0 秒触发时间。默认保护开启、0.9 秒，保持原有安全时序；关闭或延长会明确提示可能触发 EPS 故障。

## 字段与日志证据

- DBC 中 `Navi_HU` 报文 ID 为 `0x544`：`SpeedLim_Nav_Clu` 是原始道路限速，`SpeedLim_Nav_Cam` 是测速摄像头有效位。
- 旧 Carrot/IQ 实现同样以 `SpeedLim_Nav_Cam == 1` 判定摄像头，因此没有使用 `Sign_Detection` 等恒定或含义不明的字段猜测。
- 已保留路线共检查 47,025 条 `Navi_HU` 报文，摄像头位均为 0；当前尚无一次真实的正样本。实现、去抖和日志字段已验证，但首次摄像头生效仍须以后在真实路段确认。
- 最近完整路线中笼统 `commIssue` 只发生在启动约 9.93–13.08 秒；未发现应运行进程退出、CAN/Panda 故障、雷达错误或摄像头错误，因而采用有限启动宽限而不是屏蔽故障。

## 验证结果

- C3 ARM 设备端相关回归共 210 项通过。
- 新 Cap'n Proto 字段、Python 结构和规划器消息读写冒烟测试通过。
- 最近路线完成 15,855 帧开环规划重放：没有规划器/求解器故障，也没有测试参数写入。
- 设备部署前备份位于 `/data/openpilot/.codex-backups/full-release-20260918`；部署未删除或重置现有设置。
- 最新转向增量通过本地 Hyundai 36 项测试和 393 个平台子测试；测试确认可调增益不会突破 384 扭矩上限，保护触发时间不会低于 Panda 允许的 0.9 秒。
- 路线日志记录到约 455° 的方向盘角度，证明软件没有半圈或一圈的硬角度上限；85° 只是 EPS 故障保护开始计时的阈值。高速弯日志另行确认曾持续触及 384 上限，不与低速大角度保护混为一项。

## 道路验收边界

本次离线验证不能替代闭环实车验证。首次道路测试应从低速开始，驾驶员必须随时接管制动和转向，重点观察：原厂摄像头首次正样本、红灯晚识别、极低速静止前车距离，以及大角度弯道的 EPS 保护释放。EPS 保护建议先保持开启和 0.9 秒默认值；若关闭或延长，必须准备立即人工接管，出现 EPS 报错后停车重启车辆。不得依赖自动红灯停车替代驾驶员制动。
